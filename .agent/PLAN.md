## 五、Decision Gate（本轮唯一待人类裁决项）

### D-009：Agent 能否处置 dependabot 自动 PR

- **现行事实：** STATE 多轮记录「自动 PR 不碰」，构成事实上的合并禁令。
- **与既有决策的关系：** D-005（T-037 既有先例）恰恰是**关闭**这批 PR 而非合并，方向一致。真正的问题不是「能不能合」，而是「**该由谁触发这次处置**」——因为禁令导致它 5 天无人认领。
- **本轮建议（默认方案）：** 按 D-005 先例执行**批次处置**——本地一次 `pnpm install` 统一解析这 9 项、跑完整门禁、产出一个批次 commit，然后逐个关闭 9 个 PR 并留言关联到该 commit。理由：9 个 PR 全部只改 `package.json` + `pnpm-lock.yaml` **同两个文件**，逐个合并需要 9 次串行 rebase；且 PR #109 已证明**逐个合并会先合入无用的 #107 再失败**。
- **若不裁决：** 默认按上述建议执行（这与既有先例一致，属低风险可逆操作）；但**逐个合并 9 个 PR 的方案不会执行**——无人工授权不触碰自动 PR。
- **重新评估触发：** 出现高危 CVE 且因限流无法上报时，必须重新评估。
