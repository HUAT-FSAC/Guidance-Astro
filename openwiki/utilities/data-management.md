# Data Management

Data files provide configuration and content for the site.

## Data Files Overview

| File                                     | Size        | Purpose                        |
| ---------------------------------------- | ----------- | ------------------------------ |
| `src/data/home.ts`                       | 15924 bytes | Home page configuration        |
| `src/data/cars.ts`                       | 8228 bytes  | Car specifications             |
| `src/data/showcase-lab.ts`               | 48520 bytes | Showcase lab scenarios         |
| `src/data/showcase-lab-i18n.ts`          | 14413 bytes | Showcase lab translations      |
| `src/data/showcase-lab-i18n.ts.bak`      | 14030 bytes | Backup of translations         |
| `src/data/sponsors.json`                 | 259 bytes   | Sponsor data                   |
| `src/data/seasons/*.json`                | -           | Season data (2023, 2024, 2025) |
| `src/data/metrics/project-progress.json` | -           | Auto-generated metrics         |

### Data Types

```typescript
interface StatItem {
    value: string
    label: string
    icon?: string
}

interface AchievementItem {
    badge?: string
    title: string
    description: string
    ctaText: string
    ctaLink: string
    image: string
}

interface SeasonItem {
    year: string
    carImg: string
    explainImg: string
    advisor?: string
    captain?: string
    members?: { group: string; names: string[] }[]
}

interface NewsItem {
    title: string
    description: string
    image: string
    link: string
    date?: string
}

interface SponsorItem {
    title: string
    logo: string
    link?: string
}

interface SponsorGroup {
    name: string
    items: SponsorItem[]
}
```

## Season Data

`src/data/seasons/` contains JSON files for each season:

- `2023.json` - 2023 season data
- `2024.json` - 2024 season data
- `2025.json` - 2025 season data

Used by `src/components/home/sections/Seasons.astro`.

## Sponsors Data

`src/data/sponsors.json` (259 bytes) contains sponsor information.

Used by `src/components/home/sections/Sponsors.astro`.

## Metrics Data

`src/data/metrics/project-progress.json` is auto-generated by `scripts/collect-github-metrics.mjs`.

Used by `src/components/docs/ProjectMetricsDashboard.astro`.

### Metrics Collection

The `collect-github-metrics.mjs` script:

- Queries GitHub API for project data
- Updates `project-progress.json`
- Commits changes back to repository

Triggered by `collect-github-metrics.yml` workflow.
