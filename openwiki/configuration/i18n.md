# Internationalization Configuration

The site supports bilingual content in Chinese (default) and English.

## Configuration

### Starlight Locales

In `.config/astro.config.mjs`:

```javascript
starlight({
    defaultLocale: 'root',
    locales: {
        root: { label: '中文', lang: 'zh' },
        en: { label: 'English', lang: 'en' },
    },
})
```

- **root**: Default locale (Chinese) - no URL prefix
- **en**: English - URL prefix `/en/`

## Utility Module

`src/utils/i18n.ts` (3191 bytes) provides i18n utilities:

```typescript
export type Locale = 'en' | 'zh'
export const defaultLocale: Locale = 'zh'
export const locales: Locale[] = ['zh', 'en']
export const localeNames: Record<Locale, string> = {
    zh: '中文',
    en: 'English',
}
```

### Locale Detection

```typescript
export function getLocaleFromPath(pathname: string): Locale {
    const segments = pathname.split('/').filter(Boolean)
    const firstSegment = segments[0]
    if (firstSegment && locales.includes(firstSegment as Locale)) {
        return firstSegment as Locale
    }
    return defaultLocale
}
```

Detects locale from the first URL path segment.

### Path Generation

```typescript
export function localePath(path: string, locale: Locale): string {
    const cleanPath = path.startsWith('/') ? path.slice(1) : path
    if (locale === defaultLocale) {
        return `/${cleanPath}`
    }
    return `/${locale}/${cleanPath}`
}
```

### Translation Lookup

```typescript
export function t(locale: Locale, key: string, fallback?: string): string {
    const trans = getTranslations(locale)
    const keys = key.split('.')
    let result: unknown = trans
    for (const k of keys) {
        if (result && typeof result === 'object' && k in result) {
            result = (result as Record<string, unknown>)[k]
        } else {
            return fallback || key
        }
    }
    return typeof result === 'string' ? result : fallback || key
}
```

Supports nested key paths like `theme.switchTheme`.

## Translation Files

### JSON Files

- `src/content/i18n/zh.json` (7654 bytes) - Chinese translations
- `src/content/i18n/en.json` (7847 bytes) - English translations

These files contain nested translation keys for UI elements:

```json
{
    "theme": {
        "switchTheme": "切换主题",
        "themeColors": "主题色"
    },
    "nav": {
        "home": "首页",
        "docs": "文档"
    }
}
```

### Content Collection

The i18n files are loaded via Starlight's `i18nLoader()`:

```typescript
export const collections = {
    i18n: defineCollection({ loader: i18nLoader(), schema: i18nSchema() }),
}
```
