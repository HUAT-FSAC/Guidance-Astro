## 素材规格建议

| 素材类型 | 规格建议                                    | 交付方式                  |
| -------- | ------------------------------------------- | ------------------------- |
| 录屏     | 1920×1080 及以上，≤ 60 秒，MP4（H.264）     | 提交至仓库 `public/media/` |
| 数据     | 与现有场景格式一致的 JSON（见 showcase 数据） | 提交至 `src/data/`        |
| 文案     | 中文为主，英文可后置（`draft: true` 路径）   | 直接提 PR                 |

## 接入方案（供开发者参考）

1. **录屏类**：压缩后放入 `public/media/`（遵守 `pnpm quality:bundle` 图片/媒体预算），页面内以 `<video>` + 封面图接入，遵守 `loading="lazy"`。
2. **可交互类**：复用 `src/data/showcase-lab.ts` 的场景/子系统数据结构，新增 scenario 后由现有 `showcase-lab-client` 渲染，无需新框架。
3. **发布门禁**：所有新增页面需通过 `pnpm lint && pnpm test:run && pnpm build && pnpm quality:bundle`。
