智能驾驶实验室是 HUAT FSAC 车队开展无人驾驶赛车研发、调试与教学的线下基地，同时以**智能驾驶交互实验室**（Autonomous Driving Lab）的形式在本站提供线上可交互演示。

## 功能分区

线上「智能驾驶交互实验室」完整映射了线下实验室的闭环验证流程，覆盖以下子系统：

<CardGrid>
  <Card title="感知（Perception）" icon="setting">
    激光雷达 / 摄像头等传感器的数据采集与障碍识别，对应线上「发车校准」「障碍识别」等场景。
  </Card>
  <Card title="定位（Localization）" icon="star">
    组合导航与定位收敛，支撑赛道级高精定位与地图匹配。
  </Card>
  <Card title="规划（Planning）" icon="puzzle">
    路径规划与制动规划，覆盖直线高速、高速循迹与紧急场景决策。
  </Card>
  <Card title="控制（Control）" icon="tools">
    横纵向控制与执行器指令下发，完成从决策到动作的闭环。
  </Card>
  <Card title="执行器（Actuation）" icon="check-circle">
    驱动、转向、制动的底层执行与状态确认，对应「八字绕环执行」「停稳确认」等环节。
  </Card>
  <Card title="安全闭环（Safety）" icon="warning">
    急停与降级策略，保障实车与人员安全，是所有动态测试的前置条件。
  </Card>
</CardGrid>
